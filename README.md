# Telegram Schedule Bot & Widget Integration

## 1. Про проєкт
Інструмент для автоматичного вилучення та відображення розкладу занять з зовнішніх навчальних платформ у вигляді Telegram-бота та віджета.

## 2. Основний функціонал
- Парсинг та обробка розкладу занять у реальному часі.
- Відправка сповіщень та нагадувань про уроки/лекції.
- Інтеграція з іншими API для відображення актуальних змін.

## 3. Технологічний стек
- **Language:** Python 3.11+
- **Frameworks:** aiogram / Requests / BeautifulSoup
- **Environment:** Linux (Bazzite OS)

## 4. Встановлення та запуск
```bash
git clone [https://github.com/Alone-usb/telegram-schedule-bot.git](https://github.com/Alone-usb/telegram-schedule-bot.git)
cd telegram-schedule-bot
pip install -r requirements.txt
python main.py;
